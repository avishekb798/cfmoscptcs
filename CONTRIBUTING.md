# Contributing

Thank you for your interest in this project.

This repository contains the complete work for a senior design project completed at California State University, Dominguez Hills (Spring 2026). It represents a finished academic deliverable and is published for reference, transparency, and reproducibility.

**External contributions are not accepted.** This includes pull requests, code changes, and feature additions. The repository is maintained as a read-only archive of the original project.

If you have questions about the methodology, results, or implementation, feel free to open an issue for discussion.
