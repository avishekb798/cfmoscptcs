# Security Policy

## About This Project

This is an academic senior design project. It is a computational simulation framework implemented as a Jupyter Notebook and does not include any web services, APIs, network endpoints, authentication systems, or user data handling.

## Reporting Issues

If you discover a security concern related to this repository (for example, accidentally committed credentials or sensitive information), please open an issue on this repository or contact the author directly.

## Scope

This project does not accept security vulnerability reports in the traditional sense, as it is a standalone simulation tool with no deployed components. There are no supported versions or patch cycles.
